# Maritime Ferry & Weather Dashboard — Engineering Case Study

> **OSYSTIC ENGINEERING CASE STUDY · PUBLIC SHOWCASE · SANITIZED · PORTFOLIO-SAFE**

## Problem & constraints

Create a maritime information experience that combines ferry-schedule data with weather/sea-state context inside a no-code application, while adapting external data structures to searchable user-facing workflows.

## Architecture & decisions

The retained private evidence describes a Bubble.io application using REST/JSON integrations, normalized ferry data and custom HTML/CSS presentation for time-segmented weather information.

## Contribution & delivery

The documented delivery included external-data mapping, ferry-schedule presentation, maritime weather metrics, custom presentation blocks and separate coastal/ferry application surfaces.

## Evidence & outcomes

Private project documentation and a retained demo video support the existence of the delivered interface and integration work.

This public artifact does not claim exact accuracy percentages, uninterrupted provider availability, transaction/commercial value or source-code reproducibility.

## Confidentiality

The public artifact excludes client identity, private screenshots/video, commercial terms, Bubble workspace access and private API/provider credentials.
